# Volchara

Now your MacBook can respond to slaps

Inspired by [spank](https://github.com/taigrr/spank)

## What It Does
- Detects laptop slaps via Apple Silicon SPU accelerometer
- Plays sounds in 4 modes: `pain`, `sexy`, `halo`, `volchara`
- Includes status copy button in UI
- Supported formats: `mp3`, `m4a`, `aac`, `wav`
